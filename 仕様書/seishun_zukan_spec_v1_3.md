# 青春モンスター図鑑 FUKUOKA
## 企画仕様書 MVP v1.3

---

## 1. 企画概要

### タイトル（仮）
青春モンスター図鑑 FUKUOKA

### コンセプト
福岡の街やランドマークを「青春生物（青春モンスター）」として解釈・可視化するWebサービス。
ユーザーは「青春研究員」として街の生態を観察し、図鑑を集めながら福岡の魅力を発見する。

### 目的
- 福岡のオープンデータを若者が楽しめる形に変換する
- 街の個性をゲーム感覚で学べるようにする
- 診断結果や図鑑カードのSNS拡散を狙う

---

## 2. やること・やらないこと

### やること
- 街の個性をオープンデータから読み解く
- 図鑑を集める体験（未発見→発見の演出あり）
- 自分と街の相性を診断する
- SNS映えする図鑑カード・診断結果の共有

### やらないこと
- GPS・AR・捕獲ゲーム
- バトル・数値競争型ランキング
- ログイン・マルチプレイ
- データの直接表示

## 4. 青春パラメータ

オープンデータをエンタメ向けに再解釈した6指標。数値レンジは30〜98。

| パラメータ | 元データの解釈 |
|---|---|
| 青春力 | 若者人口・転入数 |
| 癒やし力 | 公園・自然・スポーツ施設 |
| 行動力 | 駅・交通アクセス（地下鉄乗車数） |
| 知性力 | 図書館・教育施設 |
| ワクワク力 | 飲食店・屋台・イベント施設 |
| 寄り道力 | カフェ・立ち寄りスポット・公園 |

### スコアリング式

```
finalScore = clamp(
  max(
    round(baseScore × reliability + characterBonus + cultureBonus),
    minimumScore
  ),
  30, 98
)
```

| データ粒度 | 信頼係数 |
|---|---|
| 街単位 | 1.00 |
| 駅単位 | 0.95 |
| 住所キーワード | 0.92 |
| 区単位 | 0.82 |

キャラ補正・文化補正・最低保証・上限キャップの詳細は `DESIGN_PRINCIPLES.md` を参照。

## 6. 未発見演出

localStorageで発見状態を管理し、図鑑一覧・詳細に演出を加える。

| 状態 | 図鑑一覧での表示 | 発見条件 |
|---|---|---|
| 未発見 | シルエット表示・名前非表示 | - |
| 発見済み | イラスト・詳細表示 | 図鑑詳細ページを開く |
| 診断発見 | イラスト・詳細表示 | 診断結果の相性上位3件に含まれる |

SSRエントリーの発見時は通常より豪華な演出を加える（アニメーション・SE等、実装時に設計）。

## 7. 診断機能

### 方式
5問・4択のスコアリング方式。各選択肢が6パラメータにスコアを加算し、
合計スコアの最大値パラメータで診断タイプを決定する。同点の場合は優先順位ルールで解決（事前定義）。

### 診断タイプ（6種）

| タイプID | 支配パラメータ | ラベル |
|---|---|---|
| wanderer | 寄り道力 | 寄り道系研究員 |
| scholar | 知性力 | 文献型研究員 |
| explorer | 行動力 | 行動派研究員 |
| healer | 癒やし力 | 癒やし系研究員 |
| enthusiast | ワクワク力 | 熱血型研究員 |
| native | 青春力 | 青春純正種 |

### 診断結果で表示するもの
- 診断タイプ名
- 相性の良いエントリートップ3（該当モンスターを自動発見状態にする）
- AIコメント（事前生成・静的テキスト）
- SNS共有ボタン

## 8. SNS共有

### OGP画像
@vercel/og（Edge Function）でサーバーサイドPNG生成。

| エンドポイント | 内容 |
|---|---|
| /api/og/monster/[id] | 図鑑カード（モンスター名・パラメータ・生態説明） |
| /api/og/diagnosis | 診断結果カード（タイプ名・相性の街） |

### X投稿文テンプレ

診断結果：
```
私は「{typeLabel}」でした。
相性のいい街は{street1}・{street2}・{street3}。
#青春モンスター図鑑 #福岡青春生態調査
```

図鑑発見：
```
「{monsterName}」を発見しました。
{ecology}
#青春モンスター図鑑 #福岡青春生態調査
```

## 9. 進捗の保持

ログイン不要。localStorageに保存する。

```json
{
  "discoveredIds": ["tenjin", "hakata"],
  "diagnosisResult": {
    "typeId": "wanderer",
    "scores": { "seishun": 8, "iyashi": 6, "kodo": 4, "chisei": 7, "wakuwaku": 5, "yorimichi": 12 },
    "timestamp": 1234567890
  }
}
```

デバイスをまたいだ同期は対象外。UI上にリセット機能を設ける。

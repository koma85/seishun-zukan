## ② スコアリング計算式

```
最終値 = clamp(
           max(
             round(基礎値 × 信頼係数) + キャラ補正 + 文化補正,
             最低保証
           ),
           30, 98
         )
```

- **基礎値**: オープンデータから算出した生値（人口・公園数・飲食店数・乗車数など）
- **信頼係数**: Tier 1 = 区単位データの粗さに応じて設定（概ね 0.85〜1.0）/ Tier 2 住所キーワード集計 = 0.92
- **キャラ補正**: データが捕捉しにくい定性的特徴を反映（最大+30）
- **文化補正**: 文化的蓄積・歴史的背景の上乗せ（最大+10）
- **最低保証**: そのエリアの特性上、下回ってはならない床値
- **上限キャップ**: 他エリアとのバランス調整のために設ける天井値
